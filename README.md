# Shuttle — Badminton Training

Shuttle is a lightweight, installable web app for a competitive badminton player's weekly training rhythm. It includes six varied sessions plus a recovery day, effort targets, session completion tracking, a streak, and a player card. All profile and completion data stays in the browser on the device.

Training sessions also include guided movement previews with an animated, rotatable 3D-style athlete, exercise cues, and interval/recovery timers with pause and skip controls.

Live app: https://taswin77.github.io/Taswin/

The site includes a canonical URL, structured app metadata, an XML sitemap, a robots.txt sitemap reference, and an IndexNow key for search discovery. Search engines decide whether and when to index the app.

## Install on Android

The app needs to be hosted over HTTPS to install and work offline. Open its hosted URL in Chrome on Android, then choose **Install app** (or **Add to Home screen**) from Chrome's menu. The app has no server or paid service dependency.

## Publish

This folder is a static site and can be deployed to a static host. GitHub Pages supports public repositories on its free plan. Publishing in Google Play is a separate path: the current Play Console registration requires a one-time US$25 developer fee and a native Android package. This project is an installable web app, not a Play Store package.

## Training note

The weekly plan is a general template, not individualized coaching or medical advice. Adapt volume and exercise selection to your coach's plan, your competition calendar, and how you feel. Stop for sharp pain and seek qualified guidance when needed.
